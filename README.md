# Class 5 Scholarship Examination – Mathematics Question Bank

A collection of mathematics model questions, question papers, and exam patterns designed to help prepare students for the **Bangladesh Primary Scholarship Examination (Class 5)**.

## 📚 About This Repository

This repository contains reference materials for understanding the mathematics question patterns and model questions relevant to the Class 5 Scholarship Examination.

The primary goal is to use these resources with **Claude AI** to generate demo scholarship examination question papers for students. The generated papers should follow the question structure, mathematical concepts, difficulty level, and question styles found in the available reference materials.

This repository is intended for educational practice, mock examinations, revision, and assessment.

## 🎯 Objectives

- Collect and organize Class 5 scholarship mathematics model questions.
- Understand the question patterns and mark distribution shown in the reference documents.
- Generate new and original practice questions based on the provided models.
- Prepare complete demo scholarship examination question papers.
- Help students practise problem-solving, mathematical reasoning, and time management.
- Create answer keys and step-by-step solutions for teachers.
- Support repeated practice through multiple question paper sets.

## 📝 Guidelines for Generating Questions

When generating a demo scholarship examination paper, Claude AI should follow these guidelines:

### 1. Follow the Reference Pattern

- Analyze the available model question papers before generating questions.
- Follow the documented sections, question types, marks, and numbering.
- Preserve the original examination structure when the reference documents clearly establish it.
- Do not assume a particular official pattern if the available documents do not verify it.

### 2. Maintain the Appropriate Difficulty Level

Questions should be suitable for Class 5 students preparing for a scholarship examination.

Where supported by the reference materials, include a balanced range of:

- Basic mathematical knowledge.
- Standard textbook-level problems.
- Multi-step calculations.
- Mathematical reasoning and application.
- Challenging problems appropriate for scholarship preparation.

### 3. Create Original Questions

- Use the reference papers to understand the question style and structure.
- Create new questions rather than reproducing entire existing papers.
- Use different numbers, contexts, and problem scenarios.
- Ensure that each question has a clear and mathematically correct answer.

### 4. Verify the Mark Distribution

- Follow the marks assigned to each question in the reference pattern.
- Ensure that the sum of the marks equals the stated total.
- Clearly indicate compulsory questions and optional choices, if applicable.
- Avoid adding sections or question types without support from the reference materials.

### 5. Prepare an Answer Key

For each generated paper, prepare a separate answer key containing:

- Question numbers and correct answers.
- Step-by-step calculations for numerical problems.
- Explanations for reasoning-based questions.
- Alternative valid solutions where appropriate.
- A final verification of the answers and total marks.
